Internationalization and localization
=======================================

The translations of PuMuKIT live in this repository and are changed like any other code, in the branch that needs
them. There is no external translation platform.

Locales
-------

| Locale | Language |
|--------|----------|
| `en` | English (source) |
| `es` | Spanish |
| `ca` | Catalan |
| `gl` | Galician |
| `eu` | Basque |
| `val` | Valencian |

`PUMUKIT_LOCALES` chooses the ones an installation offers. Any other locale shows the interface in English.

Files
-----

Every bundle keeps its strings in `src/Pumukit/<Bundle>/Resources/translations/messages.<locale>.xlf` (XLIFF 1.2). All
the bundles share the `messages` domain, so Symfony merges their files: keep each string in the bundle that uses it.
The key (`resname`) is the English text.

Adding or changing a string
---------------------------

1. Add the English text to `messages.en.xlf` of the bundle, with the same text as `source` and `target`.
2. Translate it in the same commit in `es`, `ca`, `gl`, `eu` and `val`.
3. Changing the English text changes the key: translate the new key and remove the old one if nothing uses it.

`TranslationCatalogueTest` (in `make test`) fails if an English key has no translation in one of the locales, or if a
catalogue exists for a locale that is not in the list above.

To find the strings of the templates and the code that have no translation:

```bash
bin/console debug:translation es --only-missing
```

Translations from other people
------------------------------

Send the `messages.<locale>.xlf` files of the bundles to translate. They open with any XLIFF editor (Poedit, OmegaT,
Virtaal…) and only the `target` elements change. Put the files back, then run:

```bash
make test-lint-xliff
make test
```

Adding a locale
---------------

Add `messages.<locale>.xlf` to every bundle with all the keys translated, add the locale to `LOCALES` in
`TranslationCatalogueTest` and to this list. A locale that is not complete is not added: the missing strings would show
up in English in the middle of the translated ones.

Bundles
-------

The bundles in their own repositories follow the same rules with their own `messages.<locale>.xlf`.
