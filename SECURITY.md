# Security Policy - PuMuKIT

Thank you for helping us keep PuMuKIT safe! We take the security of our video platform very seriously and appreciate your efforts to report vulnerabilities responsibly.

## Supported Versions

Security support is currently focused on the latest stable branch and upcoming major releases.

| Version | Supported                       |
|---------|---------------------------------|
| 5.1.x   | :white_check_mark:              |
| 5.0.x   | :warning: Critical patches only |
| < 5.0   | :x:                             |

## Reporting a Vulnerability

**Please do not use the public "Issues" tracker to report security vulnerabilities.**

Instead, please use the **GitHub Private Vulnerability Reporting** feature:

1. Go to the **Security** tab of this repository on GitHub.
2. Click on **Advisories** in the left sidebar.
3. Click on **Report a vulnerability**.
4. Fill out the form with details about the flaw and steps to reproduce it.

### What happens next?

* **Assessment:** Our team will review the report and either accept it or request more information within 2-3 business days.
* **Fixing:** If confirmed, we will work on a patch in a private branch associated with the Advisory.
* **Release:** Once version **5.1.0** (or the corresponding patch) is ready, we will publish the Security Advisory to inform the community.

## Responsible Disclosure

We kindly ask you to maintain the confidentiality of the vulnerability until we have been able to publish a corrected version. This protects the institutions and users who rely on PuMuKIT in production environments.

*Thank you for being part of the PuMuKIT community!*
